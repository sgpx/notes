
1. PyTorch  
   a. Custom autograd:  
      • Write a torch.autograd.Function called SoftmaxCrossEntropyFunction  
        – forward(logits, one_hot_labels): compute the mean cross-entropy loss  
        – backward(grad_out): return ∂L/∂logits = (softmax(logits) – labels)/N  
      • Wrap it in an nn.Module and compare its gradient against torch.nn.functional.cross_entropy on a small random batch.  
   b. Scaled-dot-product attention:  
      • Implement a nn.Module that takes Q, K, V (shapes B×T×D) and an optional mask.  
      • Compute scores = (Q·Kᵀ)/√D, apply masked softmax, then output = scores·V.  
      • Test on random tensors, check shapes, and ensure it’s numerically stable.  

2. CUDA  
   a. Block-wise matrix transpose with shared memory:  
      • Write a kernel to transpose a 1024×1024 float matrix in place using a 32×32 tile in __shared__ memory.  
      • Launch a grid of (1024/32)² blocks.  
      • Verify correctness by comparing to a host transpose, then measure and report throughput.  
   b. 1D convolution via constant memory:  
      • Store a small filter (length ≤ 16) in __constant__ memory.  
      • Write a grid-stride kernel that convolves an input signal of length N with that filter.  
      • Compare your result to a simple CPU implementation on a random vector.  

3. NumPy  
   a. Numerically-stable softmax:  
      • Write a function softmax(X, axis=1) that subtracts X.max(axis), exponentiates, and normalizes.  
      • Test on a 2D array, confirm rows sum to 1 and no overflow occurs for large inputs.  
   b. Vectorized cross-entropy:  
      • Given logits (shape N×C) and one-hot labels (shape N×C), implement  
          loss = –∑ labels * log(softmax(logits)) / N  
      • Do it in pure NumPy, no Python loops.  Verify against PyTorch on the same small arrays.  

4. Math fundamentals  
   a. Derive the softmax gradient:  
      • Starting from σᵢ = eˣᵢ/∑ⱼeˣⱼ, show  
          ∂σᵢ/∂xⱼ = σᵢ(δᵢⱼ – σⱼ).  
      • Then derive ∂L/∂x for L = –∑labelᵢ log σᵢ (cross-entropy).  
   b. Derivative of tanh:  
      • Show tanh′(x) = 1 – tanh²(x).  
      • Do a quick finite-difference check on a few x values to confirm.
