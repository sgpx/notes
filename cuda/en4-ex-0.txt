`threadIdx` is a special variable in CUDA (NVIDIA's parallel computing platform) that represents the unique identifier of a thread within a block. Here are some examples to illustrate its usage:

1. **Single thread block:** If you have a single block with 100 threads, `threadIdx.x` will range from 0 to 99. Each thread can work on a different element of an array or perform a unique task.

   ```c
   int my_array_element = my_array[threadIdx.x];
   ```

2. **Multi-dimensional thread blocks:** You can also create multi-dimensional thread blocks. For instance, a 2D block with 16x16 threads would have `threadIdx.x` ranging from 0 to 15 and `threadIdx.y` ranging from 0 to 15. This is useful for image processing or other 2D data structures.

   ```c
   int row = threadIdx.y;
   int col = threadIdx.x;
   ```

3. **Using threadIdx for parallel loops:** You can use `threadIdx` to create parallel loops. For example, to add two arrays element-wise:

   ```c
   for (int i = threadIdx.x; i < array_size; i += blockDim.x) {
       result_array[i] = array1[i] + array2[i];
   }
   ```

4. **Combining threadIdx with blockIdx:** To work with multiple blocks, you can use `blockIdx` along with `threadIdx`. For instance, to process a larger array in multiple blocks:

   ```c
   int array_element_index = blockIdx.x * blockDim.x + threadIdx.x;
   ```

Remember, `threadIdx` is unique within a block, while `blockIdx` is unique across all blocks. This allows you to create complex parallel algorithms by combining these variables.
